How a case moves

Architecture

A simulated field-quality investigation. The language model does not calculate. The dataframe is not stored on the graph state. Each node regenerates it from the scenario seed.

Scenario YAML

The cause, the calendar, and the injections. The printed invalid rate is not stored here.

Seeded generator

One seed produces one field file. The same YAML always yields the same rows.

Metrics in Python

Rate, Wilson interval, chi-square, p-chart, Pareto, hypothesis score, cost, and the projection are code.

One case graph

Triage once, then plan, the quality record, and a status note until the requested week. Week 4 continues into close-out.

Numeric-fidelity guard

Prose may be rewritten. A number that is not already in the facts is rejected, and the template replaces that draft.

Optional narrator

The default backend is deterministic. Local Ollama uses Llama 3.1 8B. Hosted Streamlit stays rules-only, because Community Cloud has no Ollama.

Artifacts

Memo, fishbone, 5 Whys, 8D/CAPA, Gantt, risk register, three audience notes, the Streamlit page, and a seven-slide deck.

Optional Jira

All three secrets, or a JSON file of SIM keys and no socket. That file is not the build backlog in docs/jira/backlog.json.

What stays out

  • The panel, the customers, and the field file are synthetic. This is not a medical device and not for clinical use.
  • No agent swarm, no fine-tune, and no vector database. The status color is red, amber, or green. It is not retrieval.
  • The projection clears the leading stratum on a copy of the same file. It is not observed follow-up, and the walkthrough file does not turn green.
  • The build board is project INV. The investigation dry-run uses SIM keys. Those are different files.
