1. Session 3 · The week-0 memo

Architecture

Triage runs once, at the start of the case. It writes the escalation memo from the metrics dictionary: the rate, the interval, the spec, the strata, the severity, and the first hypothesis. The complaint text is copied from the scenario. The memo does not calculate a new rate while it writes.

2. Session 3 · A number must already exist

Architecture

The fidelity guard sits between any prose and the reader. Triage, the quality record, the status notes, and close-out all pass through it. It does not compute rates. It rejects a number that is not already in the facts, which is why a model may rewrite wording and may not invent a percentage.

How this session connects

Triage runs once, at the start of the case. The memo interpolates the metrics dict, and the hypothesis list comes from the strata, not from a stakeholder sentence. The guard rejects a narrative number the facts do not contain. If a model is attached later, it may rewrite wording, and the template replaces a draft that fails.
