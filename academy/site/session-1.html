1. Session 1 · Settings and the secret boundary

Architecture

config.py is the only place that reads the Jira token and the openFDA key. Printing the settings object shows a redacted view, so a log cannot become a leak. The invalid-rate cap is calculated from the 98 percent validity promise, and a missing or unknown model backend falls back to deterministic. That is the path CI runs.

2. Session 1 · CI proves the repo, not the model

Architecture

CI is the contract that a stranger can install the package and run the tests. It does not download a model, it does not hold a Jira token, and it does not call Ollama. A second job rebuilds the learning site and fails if the committed pages drift from the generator.
