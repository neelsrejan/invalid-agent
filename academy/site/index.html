How to run it locally

The default path needs no key and no model. Deterministic templates plus the numbers Python already computed.

python -m pip install -e ".[dev]"
python -m pytest
python -m invalid_agent.graph --scenario bad_lot --week 4
streamlit run streamlit_app.py

When you want a local model, Ollama serves Meta Llama 3.1 8B. The smaller tag for a laptop demo is Llama 3.2 1B. Hosted Streamlit Community Cloud stays rules-only, because Cloud has no Ollama.

ollama pull llama3.1:8b
LLM_BACKEND=ollama LLM_MODEL=llama3.1:8b python -m invalid_agent.graph --scenario bad_lot --week 0

ollama pull llama3.2:1b
LLM_MODEL=llama3.2:1b

Practice edits stay on a branch you create from the session tag. Do not merge them into main.
