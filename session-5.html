2. Session 5 · Dry-run unless all three secrets exist

Architecture

The Jira client uses the same gate as settings. Without a site, an email, and a token, sync writes SIM keys to a JSON file and does not open a socket. Those keys are the fictional investigation. They are not the build-board keys in the backlog file.
